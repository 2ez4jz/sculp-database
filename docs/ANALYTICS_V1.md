# SCULP V1.0 · Monthly Analytics Checkpoint (2026-10-09)

## Implemented
- `src/domain/monthly-stats.js`: deterministic in-memory monthly query, input YYYY-MM, scoped to the **fictional demo bookings**. Checks the demo's business-view role before returning global totals.
- `monthly-demo.html?demo=1`: independent, inspectable monthly reporting preview. Month selector, demo role switch, amounts with CAD cents.
- `scripts/monthly-stats.test.mjs` and `scripts/monthly-stats-edge.test.mjs`: example totals and edge-case checks.

## Statistical contract
- Month uses the booking's **service date** in YYYY-MM; do not infer payment date.
- `bookings`: Completed + Confirmed + Inquiry; Cancelled reported separately.
- `completed`: Completed only.
- `amountCents`: sum of nonnegative, valid two-decimal **completed booking prices** in CAD. Missing/invalid/non-CAD prices increase `unpriced` rather than becoming zero.
- Amount is **not collected cash, net profit, or a revenue-recognition accounting figure**.
- Figures must not be generated by an LLM. User-facing AI interpretation comes later, with exploratory conclusions explicitly labeled.
- The role check in this public fictional demo is a simulation. It is **not an authentication or production confidentiality boundary**.

## Verification and limits
The two new test files are committed. Current main Verify workflow enumerates existing tests instead of auto-discovering these new files, so they are not yet included in its required CI suite. Direct checks of committed code against committed demo fixtures passed 13/13 cases on 2026-10-09, including forbidden artist access, missing prices, cancellation, invalid date, cross-month and wrong currency.

This is a **standalone demo page**; it has not been integrated into the main Insights page, Sculpy chat or authenticated Supabase analytics endpoint. No production data query is implied. The current full browser regression workflow is failing at an existing Sculpy chat launcher locator after English-first demo localization; that failure predates this module and is unrelated to monthly calculations.
