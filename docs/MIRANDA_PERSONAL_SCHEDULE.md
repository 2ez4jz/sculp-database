## 使用

登录后进入独立的 **Miranda｜个人行程** 页面。默认显示今天，点击日期可切换。两位账户均可新增、编辑、删除及勾选个人安排，也可从清单进入原工作任务。

填写标题与日期；时间未知可选「全天 / 时间待定」。航班分开记录出发、到达当地日期、时间、时区及机场、航班号。酒店填写入住到退房日期，跨日安排在覆盖日期均可见。地点、预订编号及备注为可选项。工作安排不会创建或更改客户订单。

数据仅存云端，前端不将个人行程写入 localStorage。页面重新聚焦、读取失败时重试，以及页面可见且空闲时每 30 秒同步；编辑中的草稿保留。保存使用记录版本，旧版本修改不覆盖另一人的更新；结果不明时保留同一创建编号/修改内容供重试。删除需要再次确认及当前记录版本。

## 权限与范围

仅现有有效 `sculp_jz`（operations）和 `sculp_miranda`（owner）账户可读写；新增其他管理账户不会自动得到权限。权限在数据库再次校验，不依赖导航隐藏或浏览器角色。四类行级策略覆盖读取、创建、修改、删除，匿名无表权限。新增函数使用 SECURITY INVOKER，编辑者与版本由数据库触发器记录。

个人行程由两位账户在页面手动录入与维护。聊天可说明功能、权限和页面入口。定时提醒使用个人行程记录与账户的设备订阅。
