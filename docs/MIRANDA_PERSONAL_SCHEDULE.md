# Miranda 每日个人行程与待办

日期：2026-11-21（多伦多）。状态：开发检查通过，生产数据库已安装并做只读权限验证；前端与聊天说明待部署验证，真实双账号及设备体验待用户验收。

## 使用

登录后进入独立的 **Miranda｜个人行程** 页面。月历选择日期，当天列表可按航班、酒店、工作、待办、个人安排筛选；两位账户均可新增、编辑、删除和勾选完成。

填写标题与日期；时间未知可选「全天 / 时间待定」。航班分开记录出发、到达当地日期、时间、时区及机场、航班号。酒店填写入住到退房日期，跨日安排在覆盖日期均可见。地点、预订编号及备注为可选项。工作安排不会创建或更改客户订单。

数据仅存云端，前端不将个人行程写入 localStorage。页面重新聚焦、手动刷新，以及页面可见且空闲时每30秒同步；编辑中的草稿保留。保存使用记录版本，旧版本修改不覆盖另一人的更新；结果不明时保留同一创建编号/修改内容供重试。删除需要再次确认及当前记录版本。

## 权限与范围

仅现有有效 `sculp_jz`（operations）和 `sculp_miranda`（owner）账户可读写；新增其他管理账户不会自动得到权限。权限在数据库再次校验，不依赖导航隐藏或浏览器角色。四类行级策略覆盖读取、创建、修改、删除，匿名无表权限。新增函数使用 SECURITY INVOKER，编辑者与版本由数据库触发器记录。

本版为手动录入的个人日历，不接入邮箱、航空公司、酒店或外部日历，不自动推送，也不增加聊天读取/写入行程的工具。已有客户、订单、财务与营销流程保留。重复年度或周期任务不在本版范围内。
