# MEMORA / SCULPY V3 功能完整性与实现记录

日期：2026-10-16。本文记录已实现功能、验证结果与剩余工作。功能存在不等于已完成真实业务验收。

## 产品范围

MEMORA 承载通用 CRM、团队工作区和新增业务界面。SCULPY 保留现有页面结构，重点更新后台可靠性与权限校验。

## 首轮更新

- 客户档案、活动时间线、阶段看板、内部任务与自定义字段。
- 重复客户候选检测、CSV 模板、预览和确认导入；不自动合并或覆盖已有客户。
- AI 精确查询、财务比较、图表及待确认操作卡。
- 工作流预览、到期跟进检查、每日摘要及防重复执行。
- 服务端版本校验、相同请求重试、修改前后审计与失败回退。
- 长期记忆的提出、确认、修改重审和撤销。
- 请求大小限制、工具参数校验及确认卡字段限制。

## 技术选择

保留现有运行环境、模型接口、数据库和图表实现，新增功能优先使用已有事务、结构化输出、测试和部署能力。未接入额外商业账户或新增付费服务。源码依赖标识、接口路径和许可证保留原样。

团队权限、财务业务流程、后台队列与附件权限的后续验证结果见对应版本的工作日志和发布记录。真实模型评测只使用虚构数据；输入、实际输出、预期检查和修复记录单独保存。自动检查不能代替人工对自然程度、真实设备和跨天使用的验收。

## 数据与发布要求

演示与真实业务分开；不删除或覆盖真实订单。数据库迁移必须保留原始快照，核对数量、关联和金额，并在隔离环境验证恢复。发布材料记录实际成功或阻碍，不将未验证功能标为通过。
