## 十项需求对应

1. OAuth：模拟验证 readonly/S256/hash state/固定回调、DB state 单次消费、断开与 token 隔离；真实 consent 未验。
2. 历史：分页全导入、关联范围与游标基准使用模拟；真实邮箱未验。
3. 新增：history messagesAdded、有余项时不提前前移 cursor、失败重试；真实往返邮件未验。
4. 匹配：精确邮箱与同地址重复询盘复用客户；不按姓名；歧义不自动合并。
5. 多订单：无明确唯一编号不自动归属，人工解除不会被同步覆盖。
6. 提取：分级 schema 校验、缺字段/格式拒绝；不会把输出写到确认订单字段。语义正确率未做真实评测。
7. 回复：内部英文草稿、编辑保存及脏草稿离开保护；没有发送工具、scope 或 Gmail draft 写入。
8. 安全：匿名/员工/停用账户拒绝；普通业务用户不读私有凭据；邮件脚本不执行；AI opt-in；断开后在途保存拒绝。
9. 异常：游标 404、网络/限流、重复消息与失去租约；Google 生产错误码行为需实际项目验证。
10. 手机：首轮 CI 的 320/390/768/1440px 与原界面回归通过；最后补强进入新 CI，实机仍待验收。

## 发布结论

当前仅建议进入独立测试环境授权验收。先配置 Google Cloud 与安全 secret，再运行真实邮件/多角色/设备/撤销测试；核实迁移漂移、备份及恢复后取得 JZ 生产发布确认。不能因为代码或模拟测试完成就对外称 Gmail 已接通。
