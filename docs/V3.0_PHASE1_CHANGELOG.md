# SCULP OS 3.0 Phase 1：真实开发日志

日期：2026-11-12（多伦多）。状态：开发候选，未发布。

## 实际完成

1. 读取指定仓库及 AGENTS.md；确认正式登录工作区与 300 单 Demo 的代码边界。创建独立开发分支，未改 main。
2. 核实线上基线工作区文件、GitHub 部署记录、生产数据库结构、外键、RLS、账户角色、Storage 配置及迁移历史。精确业务数量与账户明细保留在单独审核资料中。
3. 新增正式管理员 Dashboard：待处理询盘、今日任务、本周已确认预约、未完成订单、已知 CAD 合同应收；展示逾期、缺价及币种限制。查询不可用时清除旧指标并显示错误，不用 Demo 数值回填。
4. 接入任务、跟进询盘和近期订单列表及快捷操作；点击沿用现有询盘与订单详情。客户搜索分页和最小新增；任务创建支持客户/订单外键并保留原确认步骤。
5. 九区导航复用既有界面，以定位分区为主，避免重建全部页面；财务指向既有经营看板，AI 打开既有助手，系统设置保留通知及账户功能。营销只有一个简短未接入说明，邮件/外部日历不冒充可用。
6. 新增 4 组受角色保护的基础 RPC 候选迁移，复用现有表；生产未应用。新增创建请求在丢失回执时冻结输入、保留 UUID 重试；保存成功后的刷新失败不会再次提交写入。
7. 新增基础响应式 CSS，保留原有色彩、组件和移动端规则；未加入动画。自动浏览器五宽度与既有手机回归已通过；视觉人工评审和真实手机仍待验收。
8. 产品知识新增 `notReleased` 说明，保持最近已验证发布记录；不把新功能宣传为线上能力，不新增聊天写入工具。
