## 数据与权限核对

- 正式库当前 0 条订单；33 张 public 表全部启用 RLS。
- 正式角色来自有效 profiles 行和 auth.uid()，不依赖用户可修改的 user_metadata；未发现使用 user_metadata 作授权的 public policy。
- public 中没有可由 anon 执行的 SECURITY DEFINER 函数。
- `sculpy_context` 与 `sculpy_monthly_report` 为 SECURITY INVOKER；认证、owner/operations 报表范围和降权历史过滤仍在原路径内。
- Auth/RLS、事务失败回滚、并发修改、重复请求、月报精确分位和服务月/收款月口径已由现有测试覆盖。未新增真实账户或写真实订单。
- 前端只含公开 publishable key；本轮未发现可疑私钥文本。公开 Demo 的身份下拉是演示视角，不是正式授权。
