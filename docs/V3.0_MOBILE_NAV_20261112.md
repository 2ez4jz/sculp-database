# SCULP OS 3.0：手机固定菜单修正

日期：2026-11-12（多伦多）。状态：候选代码，等待远程浏览器验证和发布。

- 正式工作区 760px 及以下宽度，仅菜单行吸附屏幕顶部；SCULP OS 品牌标题随页面滚动离开，避免常驻大块页头。
- 保留横向滑动及至少 44px 点击区域，适配顶部安全区；实色背景避免内容透过菜单，浮动聊天仍在菜单之上。
- 页面跳转和表单滚动为菜单留出空间；从页面深处切换“设置”时回到设置标题，不遮挡模块内容。
- 桌面侧栏、登录页和 Demo 沿用原布局；账号权限、数据库、邮件授权和业务流程不变。

本地工作台/Gmail DOM 8 项通过。实际尝试 Chromium：本机启动因 socket() Operation not permitted 失败，不能当作浏览器验证通过。
