# Sculpy 简明分析图

继续使用唯一的 300 单虚构测试目录，真实订单尚未接入。无需用户指定图表名称。

| 问题 | 自动图表 | 统计口径 |
| --- | --- | --- |
| 服务或渠道占比 | 圆环图；类别多时用柱状图 | 订单记录数，含取消；问金额时使用对应金额 |
| 渠道、主负责人比较 | 柱状图 | 当前精确日期和筛选条件 |
| 日报 | 订单构成、状态、完成金额与到账图 | 当天或明确的截至日期，不默认全月 |
| 多段日期金额比较 | 趋势图 | 相同筛选条件，显示完整日期范围与两种金额 |
| 不同条件组合比较 | 并排柱状图 | 各组合单独精确汇总，不能拼接独立维度 |
| 排期 | 按日期、订单、参与者的时间条 | 多伦多当地时间；取消不显示，咨询仍待确认 |

图表从当前目录调用与服务器相同的只读汇总函数，不从模型文字提取数字。连续追问画图沿用最近一次报表条件；保存的是本轮图表快照，刷新后不会用新目录改写旧图。全局图仅管理者可见。

每张图说明日期、筛选条件、数量或金额口径，并附简短读图解释。未知价格不能补为零；空范围明确无数据；未来已完成和小样本显示核对提醒。收款按实际收款日期，完成金额按服务日期，两者差额不能叫利润或逾期欠款。排期最多展示前 12 条，缺少时间不画虚构时段，不能单凭图断言无冲突。

验证：10 项图表单元场景涵盖日报、组合继承、自然语言日期、自动选图、渠道比较、趋势、未知/空值、排期、转义、收款日期；浏览器检查覆盖桌面/390px 手机、刷新历史与员工隔离。原有交互、数据库、权限与 300 单基线测试继续执行。
