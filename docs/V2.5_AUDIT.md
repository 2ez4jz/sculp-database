## 数据与权限问题

1. 仓库 `20261016203324_crm_v3_task_operations.sql` 未出现在生产迁移历史，需核对实际 `crm_tasks` 状态。线上迁移版本号也有拆分与重命名；**禁止把全目录迁移直接推到生产**。
2. `reminders` 已存在，但前端角色没有 SELECT/INSERT/UPDATE/DELETE，仍遗留 TRUNCATE/REFERENCES/TRIGGER。RLS 不保护 TRUNCATE。新增候选迁移撤销这三项，提供经角色检查的最小 RPC，不恢复直接表写入。
3. RLS、函数及存储授权已纳入审计；具体生产顾问结果不写入公开版本记录。
4. 客户重复与孤立关联必须在实际数据导入后复核，空数据或样本不足不能证明完整业务可靠性。
5. 询盘通过 booking_id → bookings.client_id 关联客户，不以姓名推断同一人。
6. 托管备份、PITR、恢复保留期及生产恢复演练没有可用证据。任何迁移前须核实；本次不执行生产迁移。
7. 线上 `sculpy-chat` 是 v52，仓库历史文档提示存在不在旧 main 的后端更改。未下载比对全部部署代码，不能直接用仓库整包重发 Edge Functions。
