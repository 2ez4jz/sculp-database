# SCULPY 六位订单号

日期：2026-10-15

订单号采用 `6 + 服务分类 + 四位随机数字`，任何位置都不包含4。

| 分类 | 第二位 |
|---|---|
| 婚礼造型 | 1 |
| 婚礼试妆 | 2 |
| 活动造型 | 3 |
| 拍摄造型 | 5 |
| 商业造型 | 6 |
| 教学 | 7 |
| 个人造型（云端已有分类） | 8 |
| 尚未分类 | 0 |

- 列表最左侧显示可点击的六位单号，点击进入订单详情；日期与时间保留为独立信息。
- 详情、日历、聊天关联标签显示单号，订单搜索支持单号。
- 300单演示基线的号码一次生成，跨刷新与浏览器保持一致。旧浏览器新增订单补号后保存，不破坏原来的客户、记忆、照片与订单链接。
- 正式云端由数据库自动分配；同类订单通过事务锁与唯一索引防止并发重号，不能手动改号，取消或软删除不释放旧号。
- 内部UUID和旧序列号保留，不用公开单号作为权限凭证。
- 每类支持6561个号码，用完时报错，不产生重号。
- 新增编号后也保留最近一轮聊天上下文；超大请求只截短发送副本，原始对话仍完整保存在本地。

验证：本地159项检查，158通过、0失败、1项外部PostgreSQL条件跳过。覆盖300单唯一性、无4、分类、碰撞、容量上限、旧数据补号、原ID保留和权限隔离。CI另执行桌面/手机点击、搜索与刷新、数据库双连接强制同随机种子的重号检查以及完整回归。
