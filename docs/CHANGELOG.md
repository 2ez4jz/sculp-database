## 正式模式与安全检查

2026-11-21，已上线。站点统一进入团队工作区，旧演示书签进入登录流程。演示数据、内部文档及测试文件从网站发布包剔除。检查覆盖客户端资源、AI 接口、匿名访问、数据库角色、设备推送与依赖。核对了登录、行程、订单、沟通录音与官网询盘的边界。修复工作台新建订单、新建询盘、沟通中心打开询盘及询盘转订单的页面跳转。确认建单后可直接打开已保存的订单。开发工具升级至 Playwright 1.65.1、PGlite 0.5.17 和 pg 8.23.1。


[正式切换 #67](https://github.com/2ez4jz/sculp-database/pull/67) 已合并。[持续集成](https://github.com/2ez4jz/sculp-database/actions/runs/44954959355)通过了浏览器和 PostgreSQL 17 检查，包括并发写入、权限、虚构数据备份及恢复。完整本地测试有 269 项通过，5 项多连接用例交由 PostgreSQL 流程执行。13 组浏览器回归通过，另用发布包验证手机与桌面登录页面。此次依赖审计未报告已知漏洞。主分支 Pages 和 Actions 发布均按同一份运行文件清单排除开发资料。每次发布后，自动逐项核对线上文件内容及已移除路径的 HTTP 状态。

[网站发布](https://github.com/2ez4jz/sculp-database/actions/runs/44955246974)成功，产物共 67 个运行文件，另随包提供浏览器 SDK 的许可证。已回读正式网址、旧书签和服务端文件。线上使用无凭据请求核验，旧演示接口返回 410，团队聊天和录音转写返回 401。角色交互和订单写入使用测试账号及虚构数据验证；本次未进行真实客户写入、付费 AI 调用或实体手机推送验收。
