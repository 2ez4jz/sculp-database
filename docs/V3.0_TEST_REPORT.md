真实 PostgreSQL 的并发及备份/恢复脚本沿用既有 CI。新增 OS 数据库测试已加入 `test:database` 和 `test:postgres`；本地 PGlite 不证明真实 PostgreSQL 并发或托管 Supabase API 一致。
