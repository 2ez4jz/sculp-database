# SCULP Finance
Use integer CAD cents and explicit date semantics. Service value uses completed service dates; gross receipts use payment dates; refunded net receipts require refund ledger. Match corresponding artist wage to each completed order before calculating service contribution. Other expenses must exist before calculating company net profit. Report missing prices rather than silently filling with zero. For each period show absolute difference, percent only when denominator nonzero, and uncertainty. A financial recommendation needs evidence, projected effect and a verification metric; do not approve price changes automatically.
